Presenting

Make research talks in BOLD's visual style, by hand or with a coding agent.

To start a talk: download the template and AGENTS.md into the paper's folder, then ask your agent to read AGENTS.md and build the deck from the paper.

Using the deck

Each slide is a <section class="slide"> with a unique id. Content slides start with a small label and a title; the title slide and section dividers are navy. Use the arrow keys, Space or Page Up/Down to move between slides, Home and End to jump to the first and last, and F for full screen. The deck remembers the current slide, so a refresh returns to the same place, and each slide's id is a direct link to it, for example talk.html#results.

Every piece of text has one role, with one style: title, heading, body, small (captions), label (small uppercase), data (table cells) and math. Pick a role rather than sizing text by hand.

Conventions

These apply to any format.

  • Titles describe. Name the slide's role or the measured quantity and its conditions, for example "Observation compression at matched success", not a slogan.
  • Report measurements, not verdicts. "The spread across seeds falls to ±0.03" rather than "a stable head start". Mark speculation as such.
  • Use the paper's tables verbatim. Same rows, values, headers, bold entries and caption, copied from the LaTeX source rather than retyped. A plot can sit beside a table, never replace it.
  • Intuition first, then the math. Define every symbol before it is used.
  • One accent. Navy does the work. Use green, amber and red only when the colour carries meaning, such as agree and disagree.
  • Embed images in the file. A deck that carries its own figures can be sent and opened anywhere.
  • Check the deck in the browser you will present with.
