Skills

Presenting

Make research talks in BOLD's visual style, by hand or with a coding agent.

What's in this skill

  • 1 · The template

    A single self-contained HTML slide deck. Ten example slides, one per layout: title and section dividers, text with a figure, the problem slide, notation, a definition with a worked example, a results table, a figure with key numbers, and conclusions. Each example says when to use it.

    Open the template →

  • 2 · AGENTS.md

    Instructions for a coding agent asked to build a talk from a paper: how to start from the template, the slide structure, the type scale and components, how to take tables and figures from the LaTeX source, and the checks to run before handing the deck back.

    Read AGENTS.md →

To start a talk: download the template and AGENTS.md into the paper's folder, then ask your agent to read AGENTS.md and build the deck from the paper.
