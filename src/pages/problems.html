What do the evaluator stages mean?
  • Fully implemented: the build and full contract coverage checks pass.
  • Checked: code review, synthetic tests, known-score and invalid-submission tests, and a clean-clone run pass.
  • Validated on the actual task: a controlled run passes on the declared research data or environment.

Human approval applies to a specific release and is recorded separately. An open problem has no evaluator stage yet.
