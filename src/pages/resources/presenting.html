Presenting

Templates and conventions for research talks in BOLD's visual style.

Templates

  • HTML slide deck

    A single self-contained file, opened in any browser. Ten example slides, one per layout: title and section dividers, text with a figure, the problem slide, notation, a definition with a worked example, a results table, a figure with key numbers, and conclusions. Each example says when to use it.

    Open the template →

To start a talk, download the file, rename it, and replace the example slides with your own. Keep the slides you need and delete the rest.

Using the HTML deck

Each slide is a <section class="slide"> with a unique id. Content slides start with a small label and a title; the title slide and section dividers are navy. Use the arrow keys, Space or Page Up/Down to move between slides, Home and End to jump to the first and last, and F for full screen. The deck remembers the current slide, so a refresh returns to the same place, and each slide's id is a direct link to it (talk.html#results).

Every piece of text has one role, with one style: title, heading, body, small (captions), label (small uppercase), data (table cells) and math. Pick a role rather than sizing text by hand. Labels that contain math keep their case: uppercasing turns α or st into A or S_T.

Conventions

These apply to any format.

  • Titles describe. Name the slide's role or the measured quantity and its conditions, for example "Observation compression at matched success", not a slogan.
  • Report measurements, not verdicts. "The spread across seeds falls to ±0.03" rather than "a stable head start". Mark speculation as such.
  • Use the paper's tables verbatim. Same rows, values, headers, bold entries and caption, copied from the LaTeX source rather than retyped. A plot can sit beside a table, never replace it.
  • Define every symbol before it is used, on a preliminaries slide.
  • One accent. Navy does the work. Use green, amber and red only when the colour carries meaning, such as agree and disagree.
  • Embed images in the file. A deck that carries its own figures can be sent and opened anywhere; images left in a folder from a downloaded zip may be blocked by macOS.
  • Check the deck in the browser you will present with.
